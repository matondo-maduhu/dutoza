# DUTOZA — Firebase Rules & Setup

## 1. Weka Firestore Rules

1. Firebase Console → Build → Firestore Database
2. Tab **Rules**
3. Futa yote, bandika yaliyomo kwenye faili `firestore.rules`
4. **Publish**

## 2. Weka Storage Rules

1. Firebase Console → Build → Storage
2. Ikiwa bado haujawezesha → Get started → Start in test mode
3. Tab **Rules**
4. Bandika yaliyomo kwenye `storage.rules`
5. **Publish**
